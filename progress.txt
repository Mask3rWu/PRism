## Codebase Patterns
- Backend uses FastAPI with `lifespan` pattern for DB table creation on startup
- Config uses pydantic-settings `alias` (not `validation_alias`) for env var name mapping — use `populate_by_name=True` to allow both names
- Pass `connect_args={"check_same_thread": False}` for SQLite with FastAPI's async/thread-pool model
- Run backend from project root: `python -m uvicorn backend.main:app` (env_file path is relative to CWD)
- SQLAlchemy 2.0 ORM models: use `Mapped[]` + `mapped_column()`, `relationship()`, `back_populates` (not backref)
- Run mypy with `--explicit-package-bases` when checking code under `backend/` as a package
- Do not install `sqlalchemy2-stubs` — conflicts with SQLAlchemy 2.0's built-in typing
- Import all ORM model modules in `main.py` before `lifespan` so `Base.metadata` sees all tables at `create_all` time
- New API routers go in `backend/api/<feature>.py`, register in `main.py` with `app.include_router()`, use `prefix="/api/<resource>"` and `tags=["<resource>"]`
- Use `joinedload()` for eager-loading SQLAlchemy relationships when the response schema needs them — avoids lazy-load DetachedInstanceError
- LangGraph TypedDict state: use `NotRequired` for optional fields and annotate at construction site to avoid `dict[str, object]` inference
- LLM calls via httpx: async POST to `{endpoint}/chat/completions` with Bearer token, parse `choices[0].message.content`
- Prompt templates in .md files: load at runtime with `open()`, substitute placeholders with `str.replace()`
- Agent nodes manage their own DB sessions via `SessionLocal()` — not via FastAPI's `Depends(get_db)`
- Graph nodes return `dict` (partial state updates) — return `{"summary_result": result}` not the full state
- `CompiledStateGraph` is the return type of `.compile()`, not `StateGraph`
- LangGraph parallel fan-out/fan-in: fan-out by adding edges from one node to multiple targets; fan-in by adding edges from multiple nodes to one target (LangGraph waits for all to complete before invoking the target)
- New agent nodes touch exactly 4 files: prompt .md, node .py, states.py, review_graph.py — follow the test_suggestions.py template
- Use `is_seeded` boolean flag on entities to differentiate mock/local data from real external API data — the API layer checks the flag and skips external calls for seeded entities
- When resolving mypy cross-branch variable assignments in if/else, use separate intermediate variable names to avoid type narrowing conflicts (e.g., `github_prs` → narrow via `is None` check → assign to `prs`)
- Frontend uses Tailwind CSS v4 with CSS-based `@theme inline {}` configuration — no tailwind.config.ts file
- Next.js 16 uses Turbopack as default dev server; API proxying via `rewrites()` in next.config.ts
- Run frontend commands from `web/` directory: `cd web && npm run <script>`
